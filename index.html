Template syntax guide

Add placeholders directly into the Excel cells where values should appear.

Single-value field

Use double braces, e.g. {{Nama Sekolah}}, {{No Rujukan}},{{Tarikh}}. Each unique name is scanned automatically.

Repeatable row

Put row placeholders on the same Excel row using the row. prefix: {{row.Bilangan}}, {{row.Nama Barang}}, {{row.Kuantiti}}, {{row.Unit}}, {{row.Harga}}. The app repeats that row for each row entered.

Shared values across templates

Use the same spelling for the same field in each workbook. Field matching ignores capitalization but preserves distinct names, so keep spaces and punctuation consistent.

Download filenames

Files are named NUMBER SCHOOL NAME.xlsx in uppercase. The number is the part of the reference after the last / (so AZ/002828 gives 002828). The name stays editable; clear it to go back to automatic.

Editing templates

Replace the .xlsx in templates/ and keep the placeholders. To add a template, add its file and one line in manifest.json.

Different fields per template

Fields found only in one template still appear in the shared form. Leave a field blank if it does not apply to a selected workbook. Each download only fills placeholders present in that workbook.

Tip: Row placeholders must begin with `row.` (e.g. `{{row.Name}}`), be on one row, and inside individual cells. Additional rows copy the row's font, borders and alignment but not its formulas (e.g. the amount formula), so copy those yourself afterwards. Numbers typed into fields are saved as real numbers when the cell format is General (no "number stored as text" warning), centered in repeating rows and left-aligned elsewhere; values with leading zeros or very long digit strings stay as text. Complex formulas, merged-cell layouts and workbook-specific features should be checked after download.
